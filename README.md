# Isabela Santos

Portfólio e currículo bilíngue (PT-BR / EN) de Isabela Gonçalves dos Santos | Análise & Ciência de Dados.

## Arquivos
- `index.html`: página principal (sobre, experiência, projetos, repositórios do GitHub, habilidades, contato)
- `Curriculo-Isabela-G-Santos.pdf` / `Resume-Isabela-G-Santos.pdf`: versões em PDF

A seção "Repositórios no GitHub" carrega automaticamente seus repositórios públicos mais recentes.
O idioma pode ser forçado pela URL: `?lang=en` ou `?lang=pt`.

## Como publicar no GitHub Pages
1. No GitHub, crie um repositório público chamado **exatamente** `isabelagsantos.github.io`.
2. Clique em **Add file → Upload files** e envie todos os arquivos desta pasta.
3. Vá em **Settings → Pages** e confirme: *Source: Deploy from a branch*, branch `main`, pasta `/ (root)`.
4. Em 1–2 minutos o site estará em **https://isabelagsantos.github.io**.

## Atualizar o currículo
Edite os textos em `cv.html` (cada trecho tem uma versão `data-l="pt"` e outra `data-l="en"`).
Para gerar um PDF novo, abra o `cv.html` no navegador, escolha o idioma e use **Imprimir → Salvar como PDF**
(A4, margens "Nenhuma", com "Gráficos de fundo" marcado). Substitua o PDF correspondente.
